# CrewClock typography assets

CrewClock self-hosts only the font files used by the product UI:

- Bricolage Grotesque SemiBold for the wordmark, watchpoint, and numeric moments.
- Instrument Sans Regular, Medium, and SemiBold for the working interface.
- Evidence Mono remains a system monospace fallback for exact runtime and evidence metadata only.

Both font families are taken from their official open-source repositories and are licensed under SIL Open Font License 1.1. The complete license texts are preserved beside the webfonts in `public/fonts/`.
